# 环形殖民地 · Loop Colony

一个纯前端（Canvas + DOM）的深空殖民地增量游戏。殖民者会自己沿着环形舱段巡检，你在步道和两侧摆地形模块、设备舱，让它们联动出无人机和 buff，攒够能源后回到气闸撤离。

视觉语言受《缺氧》（Oxygen Not Included）启发：粗外轮廓、细内线、拧歪的圆、笨重但可用的机械、高饱和功能色。所有画面均为 Canvas 程序化绘制，没有使用该游戏的任何图片或素材。

## 运行

直接双击 `index.html` 即可，或在本目录启动一个静态服务：

```bash
python -m http.server 8770
```

然后打开 `http://127.0.0.1:8770/`。游戏没有构建步骤，也没有外部素材依赖（字体走 Google Fonts，加载不到时会回退到系统字体）。

## 玩法

- **自动巡检**：殖民者沿着 28 格的环自动前进，路线就是中间那条金属步道。
- **三槽模块**：每个格子有「里侧设备」「中间步道」「外侧设备」三个槽位。地形放在中间，两侧放设备，角色会真的踩过中间的地形，吃到它的踩踏 buff。
- **一对联动**：中间地形与任意一侧相邻的设备会形成配方，持续召唤对应无人机，或在经过时给角色挂 buff；两侧都放设备，会分别和中间地形联动。
- **三件套联动**：中间地形 + 两侧设备（或中间设备 + 两侧地形）凑齐 15 条特殊配方时，会触发更强的三件套联动，并替换掉普通的一对联动。配方可在图鉴里查。
- **同名叠放升级**：往已有格子上叠同名牌、或把同名格子拖过去，都会合成更高等级。升级会同时提高该格的 buff 强度、无人机强度，并提高全局金币掉落倍率。
- **不同名不可叠放**：一个槽位只能有一种名字。不同名拖过去会被拒绝。
- **拖动**：所有已放下的牌都能按住拖到别的格子（或同名格合成）。
- **buff**：显示在殖民者头顶，按「移动过的格子数」倒计时，走满就消失。
- **怪物**：普通污染生物强度更高；每 10 圈出一只污染巨兽，第 50 / 100 圈会出现深核暴君。击杀掉落金币，并有机会掉落设备/地形牌。
- **撤离**：在气闸撤离保留 100% 金币；不在气闸只能留 60%（科技可提高）；阵亡只保留 20%。金币只在结算时进入库存。
- **科技树**：局外永久成长。整棵树只有 300 个节点，全部从中央的「殖民地核心」一个点向外分叉，长出「力量 / 财富 / 工艺 / 生存 / 时间」五条主枝。关键节点是保留旧存档的 23 个命名技能，枝条之间还挂着 276 个一次性小节点。点亮前置节点后才能继续往外长，价格越远越贵。树可以拖动平移、滚轮缩放，点任一节点右侧会显示详情；全览时点节点会直接放大到那一枝。含攻速、暴击、手牌上限、结算溢价、无人机上限、溅射、每格回血、免死、全局加速等效果。
- **全局加速**：开局默认 1×，在「时间」分支点亮「超频巡检」后逐步提速，点满 4 级为 2×。加速会影响角色、怪物、无人机和所有计时。

地形单独放在中间步道上时，被角色踩过会给短暂 buff；图鉴底部有四种地形的基础踩踏效果。

## 文件

- `index.html` — 页面结构、HUD、各类弹窗
- `styles.css` — 深色铆接舱体面板 UI 样式
- `data.js` — 地形、设备、配方、无人机、buff、科技树数值
- `art.js` — 粗轮廓线、工业图元、所有地形/设备/角色/怪物的 Canvas 绘制与精灵缓存
- `game.js` — 主循环、放置/拖动、战斗、圈数、结算、科技树逻辑

存档保存在浏览器 `localStorage`（键名 `doodle-loop-save-v1`），科技树里有清空存档按钮。

## 调数值

大部分平衡参数集中在 `data.js` 和 `game.js` 的以下位置：

- 圈格数：`data.js` 的 `CELLS`
- 配方与无人机基础数值：`COMBOS` / `MINIONS`
- 怪物强度与成长：`game.js` 的 `spawnMonster`
- 金币倍率：`game.js` 的 `goldMultiplier`
- 升级与无人机强度：`game.js` 的 `spawnMinion` / `applyBuff`
- 科技树价格与效果：`data.js` 的 `SKILL_BRANCHES` / `NODE_THEMES` / `BRANCH_FANS` 与 `game.js` 的 `computeStats`
- 科技树的放射布局：`game.js` 的 `buildSkillLayout`（`TREE_FAN_SPAN`、`TREE_BASE_R`、`TREE_RING_R`）
- 环的大小与槽位密度：`game.js` 的 `resize()`（`topPad` / `bottomPad` / `R` / `pathSize` / `gap`）
